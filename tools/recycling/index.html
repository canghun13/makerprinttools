Filament Recycling and Extrusion Tools

Plan a repeatable scrap-to-spool run from material weighing through extrusion, quality checks, and level winding.

Work from measured material to accepted filament

Desktop filament recycling is a production workflow, not one conversion. Build a recipe, account for losses at each stage, check whether line speed agrees with mass output, sample diameter in two axes, and coordinate the spooler as the wound diameter changes.

Recycled Filament Blend Calculator
Plan recycled polymer, virgin polymer, and masterbatch inputs for a target finished filament batch while accounting for expected process loss.Filament Recycling Yield Calculator
Estimate usable filament after sorting, size-reduction, extrusion, and quality-control losses, with whole-spool output and stage-by-stage mass.Filament Extrusion Rate Calculator
Calculate filament mass throughput and batch run time from finished diameter, solid density, and measured line speed.Filament Diameter Quality Checker
Check a series of filament diameter readings against a target and tolerance, including mean, range, standard deviation, pass rate, and optional ovality.Filament Winder Traverse Calculator
Calculate spool RPM and traverse guide speed from filament line speed, winding pitch, core diameter, target fill diameter, and traverse width.

Keep assumptions editable

The tools do not prescribe a recycled-content ratio, additive loading, process loss, tolerance, temperature, or material profile. Enter values supported by your material documentation and your own measured runs, then keep the printed result with the batch.
